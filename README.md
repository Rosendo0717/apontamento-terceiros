# Apontamento de Terceiros

Formulário para as empresas terceiras lançarem o apontamento diário por equipe e enviarem para a usina.

- Site: https://rosendo0717.github.io/apontamento-terceiros/
- Links diretos por empresa: adicione `#montec`, `#jato`, `#equipe`, `#peracolli` (empresas novas mostram o link na Área do administrador).
- Funciona sem internet depois de aberto uma vez; envios sem sinal ficam numa fila e saem sozinhos quando a internet volta.
- Cadastro de empresas e funcionários: só pela **Área do administrador** (senha mestre, validada no servidor).
- Servidor: `google-apps-script/Codigo.gs` (Google Apps Script). A senha mestre é definida **somente no Apps Script**, nunca neste repositório.
